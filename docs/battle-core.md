# 戰鬥核心使用與暫定規則

核心位於 `src/game/catalog.ts` 與 `src/game/battle.ts`，不依賴 React、DOM、計時器或圖片。`src/pages/adventure.tsx` 已提供 `/adventure` 可操作原型。玩法依據為 [遊戲設計文件](forest-adventure-design.md)。

## 呼叫方式

```ts
import { hero, enemy, createBattle, act, settleVictory } from '../src/game/battle.ts';

let battle = createBattle([
  hero('forest_ranger', 0),
  hero('ember_knight', 1),
  hero('sun_cleric', 2),
  enemy('slime-1', 'slime'),
], 123);

// battle.active 是當前單位 ID；輪到我方時由介面提交指令。
battle = act(battle, { type: 'skill', skill: 'arrow', target: 'slime-1' });
// 普通敵人的完整 AI 屬下一階段，目前由呼叫者提供 attack 等指令。
// 勝利後以 settleVictory(battle) 取得恢復後隊伍，交由冒險層保存。
```

- `createBattle` 複製輸入，建立可序列化狀態與固定 seed 隨機序列，推進至第一個可操作行動。
- `act` 回傳新狀態；不合法指令丟錯且不改原資料、不消耗原 RNG。取消指令時不要呼叫它。
- `estimateDamage` 提供普通命中、未暴擊傷害基準（不扣護盾）；UI 顯示機率與多段傷害須另外說明。
- `simulate` 是測試／除錯用的完整結算副本，包含固定 seed 的機率結果；不得把它當成 UI 對隨機結果的確定預言。
- `bossTurn` 提供 Boss 蓄勢、爆發、破防與轉階段的可測轉移；`enemyIntent`／`enemyTurn` 共用同一小怪技能選擇，讓預告與實際執行一致。嘲諷、隱身、死亡即時重選合法目標。
- `settleVictory` 是純函式，多次讀取同一戰鬥得到相同隊伍，不累積回血；獎勵只領一次的交易需由未來冒險存檔層負責。
- `npm test` 以 Node 24 內建 TypeScript 支援執行規則測試，不需額外測試依賴。

## 已實作的規則

六職業 18 招、基礎數值、傷害／治療／屬性、暴擊／閃避、行動排序與擊退、狀態時點與控制免疫、50% 防禦、道具來源優先、復活行動機會、勝敗及 20% 戰後恢復、Boss 中斷後破防。

倒下單位仍保留於尚未消耗的 queue；輪到時若未復活則記入 spent。受到控制的單位自動跳過，但仍回 MP、處理狀態期限。狀態施加使用 action serial 區分本次新獲得效果，避免自己施放後立刻扣時間。

## 暫定實作行為（非新增使用者定案）

以下將尚未定案的邊界處理集中記錄，後續試玩可以修改：

- 行動開始：解除防禦 → MP +5 → 燃燒 → 再生 → 勝敗／死亡 → 控制跳過或選指令。燃燒致死後不靠再生起身。
- HP、傷害與恢復四捨五入；正值百分比恢復至少 1。死亡清除狀態與防禦。
- 全部指定友方技能目前允許自己；傷害落空時不附加該段狀態或驅散。順風箭避開閃避檢查，但致盲仍可能失手。
- 狀態重放取較長時間，自身本次刷新也不立即扣；同種護盾取較大剩餘吸收量，不相加。
- 控制移除後，免疫保留至持有者下一次行動結束；淨化移除控制也給予此免疫。
- 新的速度改變／復活排序會重新依速度排序尚未行動者，之前擊退位移不另保存。
- 嘲諷限制單體敵方目標，不限制全體攻擊；來源倒下或隱身則不強制鎖定。Boss 目標無效時依隊伍固定順序選可指定者，全部隱身時普通攻擊無目標但仍消耗行動。
- Boss 循環為 strike → charge → blast → recover（弱抽擊）→ charge；中斷直接轉 recover。恢復中的一次行動被暈眩跳過仍會消耗破防期限。
- Boss 蓄勢護盾不因控制跳過而自然到期，確保暈眩只延後、不中斷。爆發後移除剩餘蓄勢護盾。
- Boss 60 點護盾、600 HP、各怪數值和攻擊倍率是測試 fixture，未做平衡承諾。

## 本階段限制與後續

已包含小怪循環、Boss UI、現有高清 Q 版動畫、輸入、render_game_to_text、advanceTime 與瀏覽器操作驗證。`/forest` 透過探索交易層串接寶物、裝備、冒險庫存、存檔與完整通關流程；`/adventure` 獨立試玩仍每場完整恢復。藥盒由 Unit.itemHealBonus 傳入治療藥結算；晨露墜飾的開場護盾由 journeyUnit 建立。

### Boss 可玩原型與平衡驗證

第四場「樹靈前庭」使用現有蝕光樹靈高清 Q 版動畫。`bossIntent` 與執行共用目標選擇；橫幅顯示階段、全體爆發預告、60 點護盾長條與數值、破防窗口。打斷與半血轉階段有文字回饋；第二階段追加紫色光暈，根鬚指定兩名不同的存活可選角色，沒有額外行動。

目前保留 600 HP、60 點蓄勢盾、魔攻 32、爆發 ×2 作為第一版數值。`tests/boss-balance.test.ts` 使用只讀公開狀態的決策策略（有限道具、可負擔攻擊、蓄勢時可沉默），覆蓋不含晨光使的 10 種隊伍 × 30 種固定種子：300/300 獲勝，最長 7 回合。守火人＋拾風者＋掌燈人另以「蓄勢後防禦而非打盾」策略測試 30 種種子，30/30 獲勝，共承受 51 次爆發。這是可重現樣本，不代表所有隨機結果或任意操作都必勝。

瀏覽器另實際操作無補師隊伍，驗證蓄勢、傷害破盾、破防、兩階段與勝利；檢查桌面、390px 手機版與資產載入。既有 Google Fonts 外部請求受網路政策阻擋，使用本機替代字型，不影響戰鬥。

小怪測試起點：史萊姆依序撞擊、月露彈（魔法 ×1.2＋緩速 1）、凝膠防禦（自身最大 HP 20% 護盾，1 次行動）；苔岩小怪依序岩拳、固守、重擊（物理地 ×2，出手後移除固守並獲得破防 1）。沉默期間改用普攻但循環仍前進。每輪三招循環鎖定同一隊伍位置，下個循環換位置；無法指定時選其他有效目標。
