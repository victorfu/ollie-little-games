# 完整森林探索原型

入口為 `/forest`，首頁提供「開始探索冒險」；`/adventure` 保留獨立戰鬥試玩。森林草地、道路、樹叢、寶箱與營火已使用 Codex 內建圖片生成的繪本素材，搭配既有高清 Q 版角色／怪物；沒有使用 API key 或 SVG。原始 PNG 與來源紀錄位於 `assets/environment/storybook/`，執行時載入 WebP。

## 地圖與流程

世界為 2400×960，自由移動、三人沿路徑跟隨、點擊 BFS 尋路、鏡頭邊界與道路碰撞。WASD／方向鍵移動，手機方向按鈕亦可；E 互動、M 開啟地圖。視窗開啟時探索暫停。

| 地點 | 遭遇／內容 | 類型 |
| --- | --- | --- |
| 月露小徑 | 月露史萊姆 ×1 | 必經 |
| 林間岔路 | 月露史萊姆 ×2、林間寶箱 | 可選支線 |
| 倒木空地 | 苔岩小怪 ×1 | 必經 |
| 舊營地 | 第一處營火、旅人短箋 | 休息／換隊 |
| 石根步道 | 史萊姆 ×1＋苔岩小怪 ×1 | 必經 |
| 苔岩支線 | 苔岩小怪 ×2、舊旅人背包 | 可選支線 |
| 樹靈前庭 | 第二處營火、Boss 機制告示 | 休息／準備 |
| 樹靈入口 | 蝕光樹靈 | 互動確認後才開戰 |

三處狹窄主路安排必經遭遇；Boss 也會檢查三場主路遭遇已清除。兩條支線均非通關必要條件。怪物固定配置、不重生，只有隊長觸發；返回地圖有 2 秒接觸保護，載入有 1.5 秒。地圖僅顯示走過的道路與發現的地點，留言已讀旗標保存在存檔。

營火恢復六職業 HP／MP 與共用治療 3、復甦 1，不清空備用藥。可換人、切換造型與裝備。死亡返回最近造訪的營火；第一處營火前回森林入口。戰鬥帶入當前資源，勝利套用既定 20% 戰後恢復。

## 三件寶物

- 林間寶箱：苔紋護符（最大 HP ＋10%）、治療藥與淨化藥各一。
- 旅人背包：旅人藥盒（持有者使用治療藥，額外回復目標最大 HP 10%）、治療藥與淨化藥各一。探索用藥時由出戰隊伍中的藥盒持有者協助，回復 50%；戰鬥中必須由持有者使用。
- 首次 Boss 通關：晨露墜飾（每場戰鬥開場獲得自身最大 HP 10% 護盾，2 次自身行動）。

寶箱要求附近支線敵人已擊敗。每人只能裝一件，每件只能裝一人；更換會取代原本裝備。營火換裝後依新 HP 上限補滿。

## 通關與再次挑戰

Boss 勝利立即保存通關、結算快照與首次獎勵。返回探索時顯示亮起的引路燈、恢復明亮的森林與三人結算畫面，列出冒險時間、6 場遭遇完成數與 2 個寶箱取得數。

- 返回森林：位於第二處營火，Boss 不再出現，可以補找支線。結算保留通關當時的數據。
- 保留寶物再次挑戰：重新選三人及造型，保留三件收藏與裝備歸屬；重置地圖、遭遇、留言、營火進度、計時和備用藥，HP／MP／補給全滿。
- 再次取得已收藏寶物的寶箱：改給治療藥 ×2、淨化藥 ×1。Boss 不重複給晨露墜飾。
- 取消再次挑戰會返回結算；重新整理仍能恢復尚未關閉的結算。
- 「開始新冒險」不同於再次挑戰：經確認後清除原存檔與收藏。

## 存檔

沿用單一 localStorage 鍵 `ollie.forest.journey.v1`，內容 schema 升為 version 2；不使用雲端同步。舊 version 1 自動遷移，保留隊伍、HP／MP、物品、裝備、寶箱與已清怪物；舊位置若落在新縮窄道路的牆內，移至同一 x 的主路中央。

儲存包括位置、營火檢查點、三人造型、六職業資源、道具、收藏／裝備、怪物與寶箱旗標、已讀留言、已探索道路、已發現物件、通關／結算、冒險次數與時間。移動約每 0.8 秒保存；互動與戰後立即保存，離頁／失焦也保存。

開戰前快照不受戰鬥中的消耗影響，途中關閉會回開戰前。勝敗一產生即透過 pendingEncounter 一次結算，與世界旗標、獎勵存於同一份 JSON，不需等玩家按返回。讀檔驗證格式／版本／角色／旗標；損毀資料保留原文並顯示錯誤，儲存失敗顯示明確提示。
