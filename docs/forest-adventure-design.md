## 1. 遊戲方向與資料依據

- 三人小隊回合制冒險，探索採自由走動的小地圖。
- 六職業任選三個不同職業；任何組合都應有合理打法，不強制帶坦克或補師。
- 第一張地圖暫稱「熄燈森林」，一趟目標約 15～20 分鐘。
- 高清 Q 版角色、怪物搭配繪本感森林背景；探索斜俯視，戰鬥側視。
- 第一個 Boss 以看懂機制即可穩定過關為目標，不要求精算或依賴機率控制成功。
- 角色固定等級，先驗證戰鬥與探索，不以升級補足戰力；跳過支線、沒有寶物仍能通關。
- 既有角色、基礎數值、傷害公式、屬性相剋與完整技能樹見 [rpg-design.md](rpg-design.md)，資料見 `src/data/skills.json`、`src/data/characters.json`。
- 怪物素材規格見 [monster-assets.md](monster-assets.md)，索引見 `src/data/monsters.json`。
- 本文件定義實際第一版規則；既有文件中的完整技能樹保留作為後續擴充，並非全部投入第一版。MP 回復與狀態時間採本文件的行動時點定義。
- 需要新增圖片時使用 Codex 內建圖片生成（使用者指定 GPT-Image2），不使用 API key、不產生 SVG；實際工具未回傳模型版本時不自行宣稱已驗證版本。

## 2. 隊伍與角色

- 六職業全數開放，每職業男、女造型能力相同。
- 三人不重複職業；指定一名探索隊長，另外兩人跟隨。
- 出戰位置不代表前後排，不影響傷害或被攻擊機率。
- 營火可換人、更換隊長與裝備寶物；探索時可更換隊長，戰鬥中固定出戰成員。
- 每職業固定三個主動技能，普通攻擊、防禦、道具額外提供。
- 第一版沒有技能裝配、技能解鎖、被動技能或奧義系統。

## 3. 行動順序與狀態

### 大回合

1. 每個大回合開始，依目前速度由高到低排序，全體存活角色與怪物各有一次行動機會。
2. 同速度時我方優先，同陣營依固定位置排序。
3. 輪到我方角色時才選擇指令，無操作倒數。
4. 行動開始時回復 5 MP；因控制跳過行動也會回復。
5. 已行動者不因速度改變再次取得行動。

加速／緩速立即重排本回合尚未行動者。擊退是獨立的一次性順序效果：讓尚未行動目標往後移一位；已行動目標不受影響，也不累積到下回合。介面預覽確定的順序變化，機率擊退只標示成功時位置。

### 狀態倒數

| 類型 | 時點 |
| --- | --- |
| 破防、虛弱、緩速、嘲諷、沉默等減益 | 持有者行動結束後扣 1 |
| 護盾、堅守、鼓舞等增益 | 持有者行動結束後扣 1 |
| 燃燒、再生 | 持有者行動開始時觸發並扣 1 |
| 暈眩、沉睡 | 輪到時跳過行動並扣 1；沉睡受到傷害提前解除 |
| 隱身 | 按持有者行動倒數；自己出手或受到範圍傷害提前解除 |

- 自己在本次行動中新獲得的狀態，不在本次行動結束時扣除。
- 背刺先檢查隱身與必定暴擊，再解除隱身。
- 同種狀態不疊加，重放取剩餘時間較長者。
- 沿用既有對立增減抵銷，以及暈眩、沉睡、束縛結束後的同種控制短暫免疫；精確行動時點尚待補足。
- 防禦消耗一次行動，直接傷害減少 50%，立即生效至自己下一次行動開始前。包含全體攻擊，不減免燃燒等持續傷害、不阻止減益。先算堅守對防禦數值的影響，再套防禦減半，最後扣護盾；防禦與堅守可並存。
- 復活不新增行動：本回合尚未輪到的行動機會可以保留並依目前速度排入剩餘順序；已行動或倒下時已被跳過的機會不補發。復活本身不觸發 MP 回復，實際輪到才處理。行動條保留倒下者灰色位置，復甦預覽說明本回合能否行動。
- 普通戰鬥目標 3～5 回合，Boss 目標 6～10 回合，屬平衡目標而非強制限制。

## 4. 三種怪物

### 月露史萊姆（月）

| 技能 | 效果 |
| --- | --- |
| 軟泥撞擊 | 單體無屬性物理傷害 |
| 月露彈 | 單體月屬性魔法傷害，附加緩速 1 次行動 |
| 凝膠防禦 | 自身護盾，持續 1 次行動 |

第一場只有一隻，先撞擊再展示月露彈。沒有治療或分裂。教玩家選目標、看順序與屬性相剋。完整技能循環與護盾量待定。

### 苔岩小怪（地）

| 技能 | 效果 |
| --- | --- |
| 岩拳 | 單體無屬性物理傷害 |
| 抱石固守 | 自身堅守，持續 1 次行動 |
| 滾岩重擊 | 單體高傷害地屬性攻擊，使用後自身破防 1 次行動 |

基本循環：岩拳 → 固守 → 重擊。固守時顯示下一回合重擊目標，提供完整準備時間；重擊後露出破綻。拾風者可利用風對地優勢。

### 蝕光樹靈（影屬性 Boss）

單獨登場、不帶小怪，速度偏慢，固定循環與明確預告。

1. 根鬚抽擊：單體物理攻擊。
2. 吞光蓄勢：消耗本次行動，獲得護盾，預告下次全體爆發。
3. 蝕光爆發：全體高傷害影屬性魔法。
4. 爆發後自動進入枝核外露：自身破防至下一次行動結束；下一次僅使用較弱根鬚抽擊，隨後繼續循環。確切循環狀態轉移待實作前定義。

應對方式：

- 傷害打破護盾或驅散移除護盾，都算中斷蓄勢。
- 噤聲可以透過沉默阻止爆發，也能驅散護盾。
- 成功中斷後，Boss 下一次改用較弱根鬚抽擊，不額外跳過整次行動。
- 中斷後立即進入枝核外露（破防），直到下一次較弱根鬚抽擊的行動結束；之後回到蓄勢循環，不補放被取消的爆發。
- 蓄勢時沉默阻止爆發，也視為中斷並移除剩餘護盾；暈眩僅延後行動，不直接視為打斷。
- 也能用削弱、護盾、防禦和有限藥品承受爆發，再利用破防反擊。
- 不要求特定職業或屬性；無補師隊伍正確應對也能承受未打斷的爆發。

HP 降到一半進入第二階段：外觀與預告改變，根鬚抽擊改打兩名角色。蓄勢／爆發節奏保持，不插入額外攻擊、不清除既有狀態。Boss 保留可被干擾的招式，控制職業仍有作用。

主路清楚、兩條短支線；用路徑、燈柱與場景構圖引導。沒有特定職業才能通過的障礙。獎勵以藥品與寶物為主，少量旅人留言提供氣氛與提示。

| 地點 | 遭遇 | 性質 |
| --- | --- | --- |
| 月露小徑 | 史萊姆 ×1 | 必經，基本操作 |
| 林間岔路 | 史萊姆 ×2 | 可繞過，集中攻擊／群攻 |
| 倒木空地 | 苔岩小怪 ×1 | 必經，預告與防禦 |
| 石根步道 | 史萊姆 ×1＋苔岩小怪 ×1 | 必經，威脅優先順序 |

| 樹靈前庭之後 | 蝕光樹靈 | Boss |

- 主線三場普通戰加一場 Boss，兩場額外遭遇。
- 怪物固定配置、小範圍巡邏、不追逐、不重生；只有隊長接觸會開戰。
- 戰後短暫接觸保護，避免立刻連續開戰。
- 戰鬥勝利後，存活者回復最大 HP 的 20%（不超過上限）；倒下者以最大 HP 的 20% 起身，不再額外套一次回血。全員 MP 回滿，清除戰鬥增益、減益與剩餘護盾。20% 是已確認的第一版測試起始值。
- Boss 入口須互動才進入，不因靠近誤觸。入口告示提示打碎護盾可阻止爆發。

## 6. 營火與失敗

- 舊營地設於兩種小怪教學之後；樹靈前庭營火讓玩家完整準備 Boss。
- 互動立即恢復所有可用角色的 HP／MP、復活、清除戰鬥狀態，補滿共用補給並存檔。
- 可更換隊伍、隊長與寶物；不消耗物品，怪物不重生。
- 全滅回最近營火，恢復狀態與補給，保留寶箱與已清遭遇，不扣錢。
- 第一個營火以前全滅的返回位置尚待定義。

## 7. 藥品、寶物、背包

全隊共用背包、不限重量、不整理格子。第一版沒有商店、金幣、隨機詞條、稀有度、強化或套裝。

### 藥品與補給

| 藥品 | 測試起始效果 |
| --- | --- |
| 治療藥 | 存活角色最大 HP 的 40% |
| 復甦藥 | 倒下角色以 30% HP 復活 |
| 淨化藥 | 清除存活角色所有減益，不回復 HP |

- 營火補滿全隊共用的治療 3 次、復甦 1 次。
- 探索藥品另存為備用庫存；先消耗營火補給，耗盡才扣備用藥，確認時顯示來源。
- 營火不覆蓋備用藥品。顯示例：「治療：補給 2／3，備用藥 1」。
- 全員可用，戰鬥中花一次行動，探索中沒有行動成本。
- 禁止無效使用，如滿血治療、無減益淨化、對存活者復甦。
- 第一版不提供 MP 藥。

### 寶物

所有職業皆可裝備，每人一件，同一件不得多人共用，只能在營火更換。

| 寶物 | 測試起始效果 | 首次取得 |
| --- | --- | --- |
| 苔紋護符 | 最大 HP ＋10% | 第一條寶箱支線，另有藥品 |
| 旅人藥盒 | 持有者使用治療藥額外恢復目標最大 HP 的 10% | 第二條支線，另有藥品 |
| 晨露墜飾 | 每場開始獲得自身最大 HP 10% 的護盾，持續 2 次自身行動 | 首次擊敗 Boss |

固定效果、無需鑑定。主線不以擁有寶物為前提。

### 背包介面

- 「藥品」「寶物」兩頁；藥品頁上方固定顯示營火補給。
- 選藥後顯示三人 HP、恢復預覽與確認按鈕。
- 寶物顯示效果與裝備者；只有營火提供裝備／卸下操作。
- 新物品標記「新」，看過即消失；旅人留言不占背包。

## 8. 戰鬥畫面與操作

- 左側三名我方、右側敵人，高清 Q 版角色搭配繪本森林。
- 頂部行動條突出當前單位，已行動者變暗。
- 中央呈現動作、傷害與治療數字；角色附近顯示 HP、狀態，敵人另有意圖與目標。
- 底部提供三人 HP／MP 概況與當前角色指令：普通攻擊、三個技能、防禦、道具。
- 三招直接展開並顯示 MP；不足時停用但仍能查看說明。
- 流程為選指令 → 選目標／查看預覽 → 確認施放；確認前可取消。
- 全體、自身技能自動標示目標但仍需確認。
- 傷害預覽表示一般命中且未暴擊的預估值，機率效果另列；屬性優勢顯示 ×1.5。
- 狀態顯示剩餘次數，可查看精確說明；順序變化可預覽與取消。
- Boss 蓄勢顯示明確全體攻擊預告、護盾數值與長條；中斷後立即更新下一招。
- 防禦、相剋、沉默阻止技能均有短文字回饋。
- 滑鼠／觸控操作；鍵盤方向鍵選擇、Enter 確認、Esc 返回。
- 一般／快速動畫速度，選指令無倒數。

## 9. 探索畫面與操作

- 斜俯視小地圖，隊長在前、兩名隊員跟隨；鏡頭平順跟隨且限制於地圖邊界。
- 遮住人物的前景樹冠淡化，跟隨者不阻擋道路、不觸發遭遇。
- WASD／方向鍵移動，預設小跑，無體力條；滑鼠點地面移動。
- 點物件走近但不自動使用；E／互動鍵才執行。多物件時選擇面向且最近者。
- 手機左側虛擬搖桿、右側互動鍵，隱藏鍵盤提示。
- 背包、地圖、留言與暫停選單開啟時，怪物巡邏暫停。

| 區域 | 內容 |
| --- | --- |
| 左上 | 三人頭像與 HP，可查看狀態、技能、更換隊長 |
| 上方中央 | 進入區域時短暫顯示地名 |
| 右上 | 地圖、背包、設定與一行當前目標 |
| 下方中央 | 鄰近物件的互動提示 |
| 右下 | 共用治療／復甦補給次數 |

探索 MP 不常駐，但詳情可查。物件以外觀引導，靠近才顯示名稱與輪廓；開箱自動收取並短暫顯示收穫，留言用短篇紙張視窗。

地圖僅點按按鈕或 M 開啟，不常駐小地圖。手繪圖顯示自身位置、已探索道路、發現的營火／寶箱與開啟狀態，以及發現後的 Boss 入口。未知岔路只畫到已看見的位置。

營火介面呈現圍坐隊員與恢復／存檔結果，提供調整隊伍、查看背包、繼續冒險。

## 10. 開始、教學與存檔

- 標題畫面：繪本森林與營火；開始冒險、繼續冒險、設定。
- 單一本機存檔；有存檔時優先顯示繼續，開始新冒險須確認覆蓋。
- 短開場可跳過：森林引路燈逐盞熄滅，三名旅人循最後微光進入森林。
- 選隊畫面呈現六職業、三個位置、角色造型、定位與三招技能。
- 選滿三個不同職業並指定隊長後出發；可用「幫我選一隊」選守火人、掌燈人、晨光使，仍可修改。
- 明示「任何三個職業都能冒險，到營火還能換人」，不顯示缺坦補警告。
- 入場 HP／MP／補給全滿；教學依移動、第一場戰鬥、首次重擊預告、首次營火分段出現，可關閉與在設定重看，再挑戰不重複彈出。
- 營火、戰鬥結束、取得物品、調整隊伍後自動存檔。
- 不保存戰鬥中途；中途關閉回開戰前，須具備開戰前快照避免已耗資源帶入或重複領獎。

## 11. 通關與再次挑戰

擊敗樹靈後播放短演出：樹心光芒散入森林，引路燈重新亮起。

結算顯示出戰三人、冒險時間、遭遇完成數、寶箱發現數與首次通關獎勵。不評星、不因失敗次數扣分。

- 返回森林：回 Boss 前營火，Boss 已消失，可以補拿寶箱。
- 再次挑戰：重新選隊，重置地圖、遭遇、補給與額外藥品庫存，保留已收集寶物。
- 已擁有寶物的寶箱改給藥品，首次通關寶物不重複發放。
- 「開始新冒險」與「再次挑戰」是不同入口；收藏在覆蓋新存檔時如何處理仍需明確決定。

## 12. 實作前要補足的規則與待測數值

這些尚未在討論中定案，不能把實作選擇當成使用者已確認內容。

為讓核心可執行，部分邊界先採暫定行為，逐項記錄於 [戰鬥核心使用與暫定規則](battle-core.md)，不改變本節的待確認性質。

- 三怪 HP／攻防／速度、技能傷害、護盾量與完整 AI 轉移。
- 行動開始時 MP、燃燒／再生、死亡與控制判定的先後；重放自身既有狀態的倒數處理。
- 控制免疫期限換算、沉默對各怪物招式的分類。
- 護盾多來源是否覆蓋或合併；淨化／驅散與狀態免疫的精確範圍。
- 速度重排與已發生擊退的互動；目標死亡／隱身後的預告改選規則。
- 部分技能「同伴」能否指定自己、攻擊落空時附加效果是否生效、順風箭與致盲的互動。
- 寶物提高最大 HP 時當前 HP 如何調整；旅人藥盒是否同時作用於營火治療補給。
- 營火以前全滅返回位置、各類藥品的確切掉落與替代寶物獎勵數量。
- 探索用藥／換寶物等變更的保存時點、新冒險是否清除收藏、再挑戰裝備配置如何保留。
- 場景尺寸、碰撞與點擊尋路、觸控配置、缺少的移動方向素材如何呈現。

## 13. 第一版實作順序（已確認）

每階段都產生可驗收結果；先確認戰鬥好玩，再完成整張地圖與正式美術。

| 階段 | 工作 | 驗收結果 |
| --- | --- | --- |
| 1. 規則與資料核心 | 補足影響戰鬥的時點規則；角色、18 技能、狀態、行動條、傷害與道具資料；戰鬥邏輯與動畫分開 | 固定亂數下可重現戰鬥；針對重排、倒數、死亡／復活與資源消耗驗證 |
