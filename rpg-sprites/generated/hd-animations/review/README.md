# 動畫視覺 review 與修正

檢查範圍：12 位角色的 8 種動作，高清正常、高清 Q 版與 Q 版像素動作表；48/96px 共用同一組像素姿勢。

## 確認並修正

- 高清正常版待機向左漂移：原圖的人物間距不等於四個等寬格子的中心，匯出時卻直接扣掉格子中心。現在匹配頭部／上半身來校正平移。兩種高清風格的全部待機皆採用此對齊。
- 男女掌燈人（月光法師 `moon_witch`）高清 Q 版跑步左右晃：逐格匹配頭部／上半身，只平移水平位置，保留原本跑步的上下起伏。其他 Q 版跑步共用同一校正，晨光使也有相同位移問題。
- 女掌燈人 Q 版跑步最後一格持杖換手、身體反轉：用內建 imagegen 重繪，維持右手持杖與朝右跑步。
- 遊俠高清正常版男女跑步，以及高清 Q 版女角跑步缺少弓：用 Codex 內建 imagegen 補回連續持握的弓，並增加收腿的過渡影格。Q 版男角原本有背弓，保留原圖。
- 高清正常版女守火人防禦的靴底、男遊俠蓄力射擊的弓尖碰到原圖邊緣：用內建 imagegen 補完整輪廓與透明邊距。

所有接受的原圖皆通過透明外框與八個獨立人物的切圖檢查。被裁切或影格互相接觸的重繪候選未採用。圖像模型版本無法由內建工具確認。

`accepted.json` 記錄六張替換原圖的前後 SHA256；`prompts/` 保存最終生成提示詞。`inputs/` 保留獨立產生的女遊俠四格跑步原圖；`assemble_run.py` 只裁切／縮小這些生成畫稿並保留舊射箭列，沒有以程式繪製新姿勢。

對齊程式與完整 PNG/GIF 輸出使用相同流程，位移保存在 `public/characters/animations/hd/generation-report.json` 的 `registrationOffsets`。回歸測試檢查完整畫稿、不重新縮放的位移校正、所有待機的殘餘位移、掌燈人跑步的水平位移，以及 GIF 與 PNG 一致性。

這次 review 針對可確認的裝備、裁切與定位錯誤；畫稿仍是四格動畫，沒有增加中間格數。

## 女掌燈人 Q 版跑步第二次修正

使用者指出前次修正仍有問題：第 1、3 格與第 2、4 格的身體視角不同，僅校正位置與持杖手並未解決交替轉向。這次使用內建 imagegen 重畫全部四格，固定朝右的同一視角、臉與帽子方向、右手持杖，四格依序為右腳前伸、左腳抬膝、左腳前伸、右腳抬膝。

完整四格來源是 `inputs/moon_witch_female-chibi-run-v2.png`，兩次生成提示詞保存在 `prompts/chibi-moon_witch_female-run-v2.txt`。`assemble_run.py` 的 `connected=True` 用完整人物輪廓切圖，避免帽尖跨過 2×2 格線時被裁掉或混入鄰格；四格共用同一縮放比例，再放入原動作表的跑步列。月光揮擊沿用 `inputs/moon_witch_female-chibi-before-v2.png` 前版切出的完整姿勢，沒有重繪；`row_gap=40` 加入透明列間距，避免其帽尖被錯分給跑步人物。`accepted.json` 的 revision 2 記錄本次原圖雜湊及被取代的前次版本。
