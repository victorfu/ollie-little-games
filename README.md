### 職業外貌辨識

| 職業 | 臉部與髮型特徵 |
| --- | --- |
| 守火人 | 栗棕髮與綠眼；男性為成熟下顎與短鬍鬚，女性為杏眼、俐落眉線與成熟橢圓下顎，保留半編髮。 |
| 碎岩者 | 較方的下顎、濃直眉、短黑髮銀挑染、小麥膚色；以健壯輪廓區別守火人。 |
| 掌燈人 | 窄長臉、銀白直髮、半瞇紫眼、圓框眼鏡；男性另有短山羊鬍。 |
| 拾風者 | 銅紅捲髮、鼻頰雀斑、高顴骨與不對稱笑容；男性有鬍渣。 |
| 晨光使 | 深棕膚色、淡金緊捲髮、較寬鼻型與飽滿嘴唇；男性短鬍鬚、女性圓潤臉頰。 |
| 借影人 | 菱形尖臉、銳利灰眼、不對稱藍黑髮與嘴角微笑；圍巾不再遮臉。 |

晨光使沿用 `sun_cleric` 代號，既有分享網址不需修改。

## 展示頁操作

- 各職業預設展示女性；可切換男性／女性，網址明確指定 `gender=male` 時仍展示男性。切換職業會保留已選性別與顯示模式。
- 可查看高清正常、高清 Q 版、Q 版像素圖，或三者並排比較；窄螢幕會自動上下排列。
- 支援淺色、深色與透明格背景，以及像素圖整數倍率顯示。
- 可在 48×48／96×96 之間切換，並分別下載高清正常、高清 Q 版、48px 與 96px PNG。
- 動作動畫可播放／暫停或逐格檢查；系統偏好減少動態效果時預設暫停，仍可手動播放。
- 使用上一個／下一個按鈕，或在未聚焦操作元件時按方向鍵切換職業。

## 分享指定角色

操作展示頁時，網址會同步記錄選擇；點「複製分享連結」即可分享相同角色與設定。重新整理、瀏覽器上一頁／下一頁也會保留對應狀態。

範例（使用網站所在網域）：

```text
/?class=martial_artist&gender=female&view=compare&bg=night&zoom=4
```

| 參數 | 可用值 | 未提供或無效時 |
| --- | --- | --- |
| `class` | `ember_knight`、`martial_artist`、`moon_witch`、`forest_ranger`、`sun_cleric`、`shadow_rogue` | `ember_knight` |
| `gender` | `male`、`female` | `female` |
| `view` | `pixel`、`original`、`chibi`、`compare`、`animation` | `compare` |
| `bg` | `paper`、`night`、`checker` | `paper` |
| `size` | `48`、`96` | `48` |
| `art` | `pixel`、`chibi`、`original`（動畫風格） | `pixel` |
| `action` | `idle`、`walk`、`run`、`slash`、`thrust`、`block`、`hurt`、`fall` | `idle` |
| `zoom` | `auto`、`1`、`2`、`3`、`4`、`6`、`8`、`10` | `auto` |

舊的 `size=40`／`size=80` 分享參數分別對應新版 48×48／96×96；未指定尺寸為 48×48。`view=original` 顯示高清正常，`view=chibi` 顯示高清 Q 版。

高清動畫範例：`/?class=ember_knight&gender=female&view=animation&art=original&action=slash`；高清 Q 版使用 `art=chibi`。在高清正常／Q 版頁面點「動作動畫」，會自動採用同一風格。

動畫分享範例：`/?class=ember_knight&gender=female&view=animation&size=96&action=slash`。動作選擇會在切換職業、性別與尺寸時保留。

倍率代表偏好的整數倍；較窄螢幕仍會自動限制實際倍率，避免圖片溢出。切換顯示模式時會保留倍率設定。若剪貼簿權限不可用，頁面會顯示可手動複製的完整連結。

## 執行

```bash
npm ci
npm run dev
```

開啟 [localhost:5566](http://localhost:5566)。

網站是純前端 SPA（React + Vite + TypeScript + Tailwind CSS，路由使用 React Router）。`npm run build` 會輸出靜態檔案到 `dist/`，可部署到任何靜態主機；若之後新增其他路徑，主機需把未知路徑回退到 `index.html`。

## 角色素材

角色素材使用 Codex 內建 imagegen 生成；工具未提供模型版本，沒有使用需要 API key 的生成 CLI。像素轉換僅處理已生成的 Q 版像素來源。

- 高清正常：`rpg-sprites/generated/illustrations/` → `public/characters/originals/`，原檔完整保留
- 高清 Q 版：`rpg-sprites/generated/chibi/` → `public/characters/chibi/`
- Q 版像素來源：`rpg-sprites/generated/masters/chibi/`
- 48×48：`public/characters/<id>.png`；96×96：`public/characters/96/<id>.png`
- README 整數倍像素預覽：`public/characters/previews/` 與其 `96/` 子目錄
- 新版生成提示詞：`rpg-sprites/generated/prompts/chibi/`
- 先前 Q 版樣稿：`rpg-sprites/generated/samples/ember_knight_female-chibi-pixel.png`
- 動作來源與提示詞：`rpg-sprites/generated/animations/`；GIF 與逐格 PNG：`public/characters/animations/`
- 高清動作來源與提示詞：`rpg-sprites/generated/hd-animations/`；GIF 與全彩影格：`public/characters/animations/hd/`
- 動作索引：`src/data/animations.json`、`src/data/hd-animations.json`（分別由兩種動畫匯出指令產生）
- 網站資料：`src/data/characters.json`（由匯出指令產生，勿手改）
- 完整流程：[rpg-sprites/README.md](rpg-sprites/README.md)

重建素材（需先在 `rpg-sprites/` 執行 `uv sync`）：

```bash
rpg-sprites/.venv/bin/python rpg-sprites/sprites.py export-web
rpg-sprites/.venv/bin/python rpg-sprites/sprites.py export-animations
rpg-sprites/.venv/bin/python rpg-sprites/sprites.py export-hd-animations
```
